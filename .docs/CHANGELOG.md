# Changelog

> Significant documentation and implementation changes, newest first. Granular work logs live in phase docs; this file is the high-level history.

## 2026-10-27 (Phase 2)

- **Phase 2 — Provider layer implemented.** Four capability contracts (`TextProvider`, `ImageProvider`, `TtsProvider`, `MusicProvider` in `App\AI\Contracts`) with provider-agnostic input/result VOs (`StoryBrief`, `ScenePlanConstraints`, `CharacterBrief`, `SceneBrief`; `StoryDraft`, `ScenePlan`, `ImageResult`, `AudioResult`, `ProviderUsage`); typed exception taxonomy (`ProviderConfigurationException/Auth/RateLimit/Timeout/Request` + `ProviderHttpError` status mapping with `Retry-After` parsing). `ProviderRegistry` (config-driven; `test_only` entries hidden outside testing) + `ProviderManager` (project override → active default setting → env; actionable errors; **no silent fallback**). `CredentialStore`: env-first with encrypted `provider_settings.credentials` fallback, switchable via `PROVIDER_CREDENTIAL_STORE=env|database` (D-021; empty string = no stored credential). `ProviderGateway`: pre-call `DAILY_PROVIDER_BUDGET_USD` ceiling check, bounded exponential backoff with jitter + `Retry-After` awareness, **per-attempt `provider_calls` ledger rows** (capability, provider, model, status, http_status, estimate/actual, tokens, duration, `request_fingerprint`, sanitized error). `ProviderHttpClient` + `SecretRedactor`: provider HTTP logging with authorization headers/keys/secret params redacted — real request headers untouched on the wire.
- **Settings UI + rules:** `/settings/providers` Inertia page (JS-only) for system provider settings with write-only credential field ("API key saved (hidden)" indicator), per-capability default exclusivity (application-enforced in a transaction), activate/deactivate/delete with dangling project-override cleanup; `ProviderSettingsRequest` + `ProviderIsKnown`/`ProviderConfig` rules reject unknown providers and unknown config keys. Authorization: any authenticated user in the MVP (D-019); `ProviderSettings` gains `#[Hidden(['credentials'])]` so serialization can never leak it. Per-project override resolution shipped and tested; override UI deferred to Phase 3 (D-022).
- **Fakes + tests:** deterministic fake providers for all four contracts (tiny valid PNG/WAV fixtures written to the private test disk) with injectable failures (auth/rate-limit/timeout/malformed/request), registered in testing only (D-020: registry has no real vendors until D-007 verifies them). `Http::preventStrayRequests()` enforced suite-wide. New factories: `ProviderSettingsFactory`, `ProviderCallFactory`, `GenerationJobFactory`.
- **Verification:** `php artisan test` → **172 passed / 1170 assertions** (baseline 70/237 — all Phase 0/1 tests still green; zero network calls; no schema changes, `migrate:status` clean); `npm run build` ✓ (JS only); Pint ✓. Docs updated: [phases/PHASE_02_PROVIDER_LAYER.md](phases/PHASE_02_PROVIDER_LAYER.md), [PROVIDER_INTEGRATION.md](PROVIDER_INTEGRATION.md) (final contract signatures), [DECISIONS.md](DECISIONS.md) (D-019–D-023), [DATABASE_DESIGN.md](DATABASE_DESIGN.md) (credential sentinel note), [PROGRESS.md](PROGRESS.md). D-007 remains unresolved by design — no vendor slugs/endpoints/prices added.

## 2026-10-27 (Phase 1)

- **Phase 1 — Domain model implemented.** 10 migrations per [DATABASE_DESIGN.md](DATABASE_DESIGN.md) (`projects`, `assets`, `stories`, `characters`, `scenes`, `dialogue_lines`, `audio_licences`, `provider_settings`, `generation_jobs`, `provider_calls` — latter five structural for Phase 2); 10 Eloquent models using `#[Fillable]` attributes (D-010) with PHP 8.3 backed enums (12 enums in `app/Enums/`); 5 project-scoped ownership policies; `DurationValidator` (target 30–90 s, tolerance **±2.0 s** — D-017 confirmed) and `ScenePlanValidator` services; `SpeechBubbleSettings` JSON rule; CRUD (dashboard cards, project create/edit/delete, story editor, character manager, scene storyboard with reorder + completion gate, dialogue lines) via Form Requests + scoped route bindings; 7 Inertia pages in JS only.
- **Schema decisions (D-009 → Confirmed):** status/mode columns are strings + PHP enums (not native MySQL ENUM); `characters` enforces unique `(project_id, name)` (duplicates rejected per project, allowed across projects); `speech_bubble_settings` shape defined and validated (style/position/max_width_percent/background_color/font_size); `voice_config` stays unstructured until Phase 5; scene renumbering uses a two-phase offset update inside a transaction to respect the `(project_id, number)` unique index; Laravel 13 skeleton's base controller has no `AuthorizesRequests` — added explicitly.
- **Testing environment change:** automated tests now run on dedicated MySQL DB `cartoon_studio_testing` (instead of SQLite `:memory:`). SQLite `:memory:` proved flaky on this Windows machine (tests intermittently lost their wrapping transaction and silently committed fixtures) and the Laravel 13 SQLite connector refuses missing files, breaking `migrate:fresh` in some suites. Documented in [PROGRESS.md](PROGRESS.md).
- **Verification:** `php artisan test` → **70 passed / 237 assertions** (twice on fresh testing DBs, zero fixture leakage); `npm run build` ✓ (JS only, zero `.ts`); Pint ✓. GitHub remote `origin` (`git@github.com:san-ratul/panelpop-studio.git`) added; history pushed (no force-push; `.env`/secrets verified untracked).
- **Docs updated:** [phases/PHASE_01_DOMAIN_MODEL.md](phases/PHASE_01_DOMAIN_MODEL.md), [DATABASE_DESIGN.md](DATABASE_DESIGN.md) (validated), [DECISIONS.md](DECISIONS.md) (D-009, D-017), [reference/ACCEPTANCE_CRITERIA.md](reference/ACCEPTANCE_CRITERIA.md), [PROGRESS.md](PROGRESS.md).
